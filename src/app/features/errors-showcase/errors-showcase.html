Live Routes

404 is the wildcard route; 403 is /not-authorized

404 — Not Found

403 — Not Authorized

Reusable For Any Error

Usage

<!-- one shared layout for every error screen -->
<app-error-page
  code="404"
  title="Page not found"
  message="..."
  icon="bi bi-compass"
  tone="primary"        <!-- primary | danger | warning -->
  [homeLink]="'/dashboard/admin'"
  homeLabel="Back to dashboard"
/>

// Guarding a route by role — sends unauthorized users to /not-authorized:
{{ '{' }}
  path: 'payrolls',
  canActivate: [roleGuard(['admin', 'finance'])],
  loadComponent: () => import('./payrolls').then(m => m.Payrolls),
{{ '}' }}
